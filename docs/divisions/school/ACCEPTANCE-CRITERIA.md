# School Division — Acceptance Criteria

- [ ] School tenant creation and verification are defined and implemented.
- [ ] School admin, teacher, assistant and student permissions are explicit.
- [ ] Teacher access is restricted to assigned classes and required fields.
- [ ] Student access is restricted to own records and assigned learning.
- [ ] Roster import validates schema, duplicates, tenant ownership and errors.
- [ ] Class/cohort transfer and withdrawal revoke prior access.
- [ ] Course assignments are scoped to correct school/class.
- [ ] Teacher progress views use approved aggregation and identifiers.
- [ ] Student records are not exposed in public pages, URLs, logs or analytics.
- [ ] Safeguarding/support visibility is defined and access-controlled.
- [ ] Retention, deletion, export and offboarding rules are documented.
- [ ] Accessibility, responsive behaviour and recovery are verified.
- [ ] Tests include two schools, multiple teachers/classes and denied cross-school access.
- [ ] Minors' data handling receives jurisdiction-appropriate review before launch where applicable.
