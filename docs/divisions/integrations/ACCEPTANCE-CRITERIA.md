# Integrations Division — Acceptance Criteria

- [ ] Every active provider has a vendor-register entry.
- [ ] Data flow and purpose are documented for every provider.
- [ ] Exact fields shared are minimised and approved.
- [ ] Processing region, subprocessors, retention and deletion are known or explicitly blocking.
- [ ] User-facing notice and consent/legal basis reviewed.
- [ ] DPA/contract and incident obligations reviewed where required.
- [ ] Credentials/signing secrets are server-only and rotatable.
- [ ] OAuth scopes/API permissions are least-privilege.
- [ ] Webhook signatures, replay protection and idempotency verified.
- [ ] Provider failure, timeout, retry, revocation and deletion tested.
- [ ] Payment unlock uses authoritative server-side verification only.
- [ ] Analytics events contain no unnecessary PII or learner content.
- [ ] AI inputs/outputs follow approved retention and training-use disclosures.
- [ ] No vendor enabled with unresolved critical privacy/security questions.
