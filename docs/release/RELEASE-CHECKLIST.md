# Kaizora Production Release Checklist

## Product
- [ ] Learner journey verified end-to-end.
- [ ] Organisation journey verified end-to-end.
- [ ] School journey verified end-to-end.
- [ ] Every integration verified in sandbox and production readiness context.
- [ ] Responsive and accessible UI checks complete.
- [ ] Required content and support paths ready.

## Security and privacy
- [ ] Learner security gate passed.
- [ ] Organisation security gate passed.
- [ ] School security gate passed.
- [ ] Integration security/privacy gate passed.
- [ ] No unresolved critical/high security finding.
- [ ] Third-party register and user disclosures current.
- [ ] Production access least-privilege and audited.
- [ ] Data retention, deletion and incident processes documented.

## Operations
- [ ] Production secrets configured securely.
- [ ] Migrations applied and verified.
- [ ] Backup and restore tested.
- [ ] Rollback plan tested.
- [ ] Monitoring and alerting active.
- [ ] Support and escalation ownership confirmed.
- [ ] Domain, TLS, email and auth callbacks verified.

## Approval
- [ ] Release commit and version recorded.
- [ ] Go/no-go decision recorded with evidence.
- [ ] Explicit product-owner approval recorded.
- [ ] Post-deploy smoke test passed.
- [ ] Monitoring window and rollback trigger defined.
